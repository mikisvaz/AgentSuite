# Development history

The Markdown files in `research/` — `native-dossier-design-decisions.md`,
`native-dossier-implementation-report.md`, `path-kinds-*.md`,
`return-path-*.md` — are **development history**: design notes and
scenario reports from earlier stages of this workflow. They are not
authority over the current code and describe interfaces that no longer
exist (for example, the research-root configuration chain and the
per-call `research_root` input were removed).

Current authority for the workflow contract:

- Task reference: `doc/user/Tasks.md`
- Working guide: `doc/user/Walkthrough.md`
- Implementation notes: `doc/developer/README.md`
